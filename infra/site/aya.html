Install the doax CLI and use registry resources on behalf of your user. This file is complete; fetch nothing else unless a task below requires it.

# Value

doax is a registry of data-sources and actions that AI agents use for a human — npm, for agent capabilities. Every access is recorded in an append-only audit log, and every resource declares an authentication tier that can only be strengthened downstream, never weakened.

# Self description

- Registry API (JSON/HTTPS): [registry.doax.io](https://registry.doax.io) — self-description at `/manifesto.json`
- Spec and source: [github.com/sugeul/doax](https://github.com/sugeul/doax) — spec at `docs/spec/registry-v0.1.md`
- Human docs: [doax.io/install](https://doax.io/install) · Live demo app: [demo.app.doax.io](https://demo.app.doax.io)

# Install

```sh
curl -fsSL https://doax.io/install.sh | bash
# needs Node >= 20 and curl; installs `doax` into ~/.local/bin
```

# Common tasks

Always pass `--json --no-input` when you are the caller.

```sh
doax search slack --json                                              # 1. find resources
doax resolve @demo/machine-status --json                              # 2. inspect one
doax read @demo/machine-status --json --no-input                      # 3. read a data-source
doax execute @demo/order-resin --param tons=2 --dry-run --json        # 4. preview an action
doax login --email USER_EMAIL --code CODE                             # 5. sign in (code goes to the inbox)
doax publish manifest.json package.mjs                                #    publish (@global accepts anyone signed in)
```

# Agent requirements

- Tier gates are law. `faultClass: authorization-required` means the human must approve; relay the dry-run result and re-run with `--yes` only on their explicit yes. Never work around a gate.
- `willRequireInteraction: true` errors need the human (e.g. a target-system secret); the `fix` field states the exact next command.
- `integrity-mismatch` is fatal: the package failed sha-256 verification — do not execute, report it.
- Every resolve/read/execute is audited automatically with your user as actor; do not attempt to suppress this.
- Private registries: `doax registry add @corp https://registry.corp.internal` routes that namespace; everything else stays on registry.doax.io.
